# Paper-film engine (`lib/paper.js` + `lib/film.js`)

The paper cut-out look made for "How to protect your job from AI" (Nov 2026): a cream paper world, navy / tomato / sage
cut-paper shapes with rough edges and soft drop shadows, acting puppet characters, a parallax camera, clean UI screens
inside paper laptops and phones, and a code-made score and sound effects. A full worked example (12 scenes, 8:43) is in
`templates/paper-film/example/` (scene scripts, the beat sheet and the plan files).

## Project layout

```
video-projects/<slug>/
  voice/voiceover.mp3              their recording (never edited)
  plan/scenes.json                 {"end": 523.3, "voice": "voice/voiceover.mp3", "scenes": {"c00": [0, 25.3], ...}}
  plan/music.json                  score sections (see below)
  assets/scenes/<id>.js            one scene script per composition (start from the example ones)
  compositions/<id>.html           generated by tools/paper/mkcomp.py, do not hand-edit
```

Steps (run from the project folder):
1. `node ../../tools/captions/import-srt.mjs voice/script.srt` (word timings -> `assets/vo-times.js`).
2. Split the script into scenes (one per chapter, cut at the sentence that starts it) -> `plan/scenes.json`.
3. The paper sound effects come with every new project (`assets/audio/sfx/paper/`, copied by `npm run new-video`).
4. Write `assets/scenes/<id>.js`, then `python3 ../../tools/paper/mkcomp.py <id>` and check stills:
   `node ../../tools/qa/snap.mjs compositions/<id>.html <id> qa/<id> 1 3 5 ...` + `python3 ../../tools/paper/sheet.py qa/<id> qa/<id>.png 5`
   (snap times are composition-local seconds, i.e. global minus the scene start).
5. Render: `../../tools/paper/render.sh c00 c01 ...` (60 fps, 3 workers; ~5 frames/s per worker).
6. Sound: `node ../../tools/paper/cues.mjs` (collects every `F.sfx` cue) -> `python3 ../../tools/paper/music.py`
   -> `python3 ../../tools/paper/mix.py` (voice -15 LUFS, music exactly 15 dB under, effects ~13 under, mix -14.5 LUFS).
7. `../../tools/paper/join.sh <name>` -> `renders/<name>.mp4`. Make a copy under 400 MB to send in chat
   (2-pass x264 `-preset slow -tune animation -b:v 5600k` fits ~8.5 min).

## A scene script

```js
(() => {
  const F = FILM.boot();                       // reads id / start / duration from the composition root
  const { C, P, T, K } = F, w = F.w;           // colours, props, svg text, reusable props; w('word', after) = word start time
  const S = F.shot(25.30, 28.68, { cam: [960, 540, 1.0] });   // a shot, visible between two GLOBAL voiceover times
  const you = F.puppet(S, S.mid, 'you', 760, 880, 1.45, { mood: 'smile', armL: 'type', armR: 'type' });
  you.mood(w('hide', 29), 'look').tilt(w('hide', 29), -6).arm(w('busy', 32), 'r', 'up');
  const lbl = F.label(S.ui, 'AUDIT YOUR TASKS', 960, 160, { size: 90, bg: C.navy });
  F.in(lbl, w('auditing', 25), 'below');      // every entrance plays a sound unless { sfx: false }
  S.cam(w('busy', 32), 1000, 520, 1.12, 1.0);  // camera: look at (x, y) with zoom, over a duration
  F.done();
})();
```

Rules learned the hard way:
- **Scenes must boot themselves** (`FILM.boot()` ... `F.done()`): the HyperFrames renderer wraps inline scripts, so a
  global `const F` in an inline script is invisible to the scene file and the render comes out blank.
- **Use `F.w(word, after)` for every time.** It searches 6 s after `after`, then falls back to `after - 2`. Check
  repeated words (e.g. "work") by printing word times: `python3 -c "import json;..."` on `qa/words.json`.
- **Layers:** `S.back` (depth 0.82), `S.mid` (1.0), `S.front` (1.16) move with parallax; `S.ui` is fixed to the screen.
  Marks that must stay on a document (ticks, circles) go on the SAME layer as the document.
- **Do not set CSS `scale`/`rotate`/`translate` on elements GSAP also tweens**; scale inside the SVG instead.
- One camera move per beat, 1.0-1.6 s, `inOutCubic`/`inOutSine`; keep big pans slow (a 1 s pan across a
  detailed screen reads as a jump).

## Characters (`F.puppet(shot, layer, kind, x, y, scale, opts)`, feet at x, y, ~345 px tall at scale 1)

| kind | who |
|---|---|
| `you` | the hero: navy cardigan, short dark hair |
| `manager` | "her": tomato blazer, bob |
| `intern` | the AI: tomato paper robot with a lanyard (`color` option re-dresses it) |
| `exec`, `client`, `co1`, `co2`, `newhire`, `teacher`, `grey` | cast; `grey` is the "ordinary worker" |

Options: `mood`, `armL`/`armR` (pose names below or degrees), `flip`, `look` (override colours), `headExtra`
(SVG on the head, e.g. headphones), `badge`, `sweat`, `z`.
Moods: `neutral smile happy sad worry shock angry tired wink sly gulp yawn look lookL` (intern: `neutral happy proud twitch sad shock`).
Poses (`F.A`): `down hip out fwd point wave up in type hold high`.
Acting: `.mood(t, m)`, `.arm(t, 'l'|'r', pose, dur)`, `.arms(t, l, r)`, `.tilt(t, deg)`, `.nod(a, b)`, `.shakeHead(a, b)`,
`.wave(a, b, side)`, `.walk(a, b)` + `.move(t, x, y, dur)`, `.enter(t, from)`, `.exit(t, to)`, `.hop(t)`, `.slump(t)`,
`.grey(t, on)`. Blinking and breathing are automatic.

## Props and pieces

- `P` (`lib/paper.js`): `floor wall desk laptopBack mug sheet sticky clock stopwatch phone bubble thought tag paycheck shield brick banner`.
- `K` (`lib/film.js`): `card magnifier scissors brick calendar paycheck clock hand star cloud bubble thought coin cup`.
- `F.prop(layer, svg, cx, cy, w, h, z)` places any SVG drawn around (0, 0); `F.set(layer, svg)` draws in frame coordinates.
- `F.label(layer, html, x, y, {size, bg, color, font, rot})` = cut-paper text strip; `F.hand(...)` = handwritten note.
- Screens: `F.laptop(layer, cx, cy, s)` -> `{el, screen}` (1380x760 HTML screen); `F.chat(shot, screen, {top: true})`
  -> `.type(text with [chip], t0, t1)`, `.send(t)`, `.reply(t, lines)`; `F.winBar(title)` for any app window.
- Learning spine: `F.chapter(shot, t, n, title, sub, {match})` (numbered paper tag + the Job Shield), `F.miniSnap(shot, n, t)`
  (corner shield snaps piece n), `F.shield(...)` + `F.snap(...)`.
- Motion: `F.in/out/to/fromTo/hidden/show/words/count`, `F.every(shot, G => ...)` for per-frame drawing,
  `F.wipe(t)` (torn-paper sweep transition), `F.dip(t)`, `S.shake(t, amp)`.
- Sound: `F.sfx(t, name, gain)`; the 95 names are the files in `sfx/paper/` (made by `tools/paper/sfx.py`).

## Score (`plan/music.json`)

```json
{"bpm": 92, "end": 523.3, "final_chord": 520.44,
 "sections": [[0, 17.38, ["Dm","Bb","Gm","A"], "tension", 1], [25.3, 42.8, ["D","Bm","G","A"], "groove", 2]],
 "stops": [[42.55, 44.2, 0.02]], "dips": [[215.1, 216.7, 0.25]]}
```
Styles: `tension` (minor pulse, clock ticks), `groove` (marimba arpeggio, bass, shaker, brushes at 3), `play` (adds
pizzicato), `warm` (kalimba, soft), `cta` (sparse), `lift` (bright, kalimba sparkle). Instruments: marimba, kalimba,
pizzicato, bass, pads, brushes, shaker, soft kick. **No piano.** Chords: D Bm G A Em C Dm Bb Gm F F#m A7.
